第一部分：知识复习

§7-1 旋转矢量法、复数表示与简谐振动能量

1. 旋转矢量法与复数解法
由 $\ddot{x}+\omega_0^2 x = 0$ 得 $x=A\cos(\omega_0 t+\varphi_0)$；利用欧拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$，引入复位移： $$z(t) = A e^{i(\omega_0 t + \varphi_0)} = \tilde{A} e^{i\omega_0 t}, \quad \tilde{A} = A e^{i\varphi_0}$$ 实际位移 $x(t) = \operatorname{Re}[z(t)]$；求导即乘 $i\omega_0$：$\dot{z} = i\omega_0 z$，$\ddot{z} = -\omega_0^2 z$。
2. 简谐振动的能量守恒
$$\begin{aligned} E_k(t) &= \tfrac{1}{2}mv^2 = \tfrac{1}{2}kA^2\sin^2(\omega_0 t + \varphi_0) \\ E_p(t) &= \tfrac{1}{2}kx^2 = \tfrac{1}{2}kA^2\cos^2(\omega_0 t + \varphi_0) \\ E &= E_k + E_p = \tfrac{1}{2}kA^2 = \tfrac{1}{2}m\omega_0^2 A^2 = \text{常量} \end{aligned}$$ 周期平均值：$\overline{E}_k = \overline{E}_p = \frac{1}{4}kA^2 = \frac{1}{2}E$。
图：旋转矢量投影与复平面表示（实时动画）

【思考与辨析 I】为什么 $E_k = \frac{1}{2}mv^2$ 不能直接用复数法？

1. 直接套用复数法的“翻车”现场
记 $\theta = \omega_0 t + \varphi_0$，复速度 $\dot{z} = i\omega_0 A e^{i\theta}$。
若像求位移那样“先在复数域平方，再取实部”： $$\begin{aligned} \operatorname{Re}\!\left[\tfrac{1}{2}m\dot{z}^2\right] &= \operatorname{Re}\!\left[-\tfrac{1}{2}m\omega_0^2 A^2 e^{i2\theta}\right] \\ &= -\tfrac{1}{2}kA^2\cos(2\theta) \end{aligned}$$
  • 荒谬结论：动能竟然在 $\left[-\frac{1}{2}kA^2,\, +\frac{1}{2}kA^2\right]$ 间周期性变号，出现了负动能！
  • 真实动能：$E_k = \frac{1}{2}kA^2\sin^2\theta = \frac{1}{4}kA^2(1 - \cos 2\theta) \ge 0$。
2. 本质原因：平方是非线性运算
设复数 $w = a + bi$，则： $$\operatorname{Re}[w^2] = a^2 - b^2 \neq a^2 = (\operatorname{Re}[w])^2$$ 直接平方取实部，多减去了虚部的平方 $b^2$！
一般地，对任意复数乘积：$\operatorname{Re}[w_1 w_2] \neq \operatorname{Re}[w_1]\operatorname{Re}[w_2]$。
3. 能量/功率的正确复数算法
  • 瞬时动能：必须先取实部再平方 $E_k = \frac{1}{2}m(\operatorname{Re}\dot{z})^2$；
  • 周期平均动能：可用复共轭一步算出： $$\overline{E}_k = \tfrac{1}{4}m\,\dot{z}\dot{z}^* = \tfrac{1}{4}m|\dot{z}|^2 = \tfrac{1}{4}kA^2$$

【思考与辨析 II】那为什么求导与解方程可以用复数法？

1. 只用实微积分证明 $\frac{\mathrm{d}}{\mathrm{d}t}e^{i\omega_0 t} = i\omega_0 e^{i\omega_0 t}$
自变量 $t$ 为实数，复函数求导即实部、虚部分别求导。将 $e^{i\omega_0 t} = \cos\omega_0 t + i\sin\omega_0 t$ 展开求导： $$\begin{aligned} \frac{\mathrm{d}}{\mathrm{d}t}e^{i\omega_0 t} &= -\omega_0\sin(\omega_0 t) + i\omega_0\cos(\omega_0 t) \\ &= i\omega_0\big[\cos(\omega_0 t) + i\sin(\omega_0 t)\big] \quad (i^2 = -1) \\ &= i\omega_0\,e^{i\omega_0 t} \end{aligned}$$ 几何直觉：速度比位置超前 $90^\circ$，而复平面上乘以 $i$ 恰好就是逆时针旋转 $90^\circ$！
2. 合法性基石：线性运算与 $\operatorname{Re}[\cdot]$ 可交换
对于加减、乘实常数、对实变量 $t$ 求导等实线性运算：
  • $\operatorname{Re}[z_1 + z_2] = \operatorname{Re}[z_1] + \operatorname{Re}[z_2]$
  • $\operatorname{Re}[c\,z] = c\operatorname{Re}[z]\quad (c\in\mathbb{R})$
  • $\dfrac{\mathrm{d}}{\mathrm{d}t}\operatorname{Re}[z(t)] = \operatorname{Re}\!\left[\dfrac{\mathrm{d}z}{\mathrm{d}t}\right]$
故只要方程是线性的（简谐/阻尼/受迫振动、波的叠加），复解的实部必严格满足原实方程。

【例题 1】人形机器人关节模组齿轮传动模型

题目
人形机器人关节模组中传动机构的简化模型：大齿轮固定，圆心为 $O$；小齿轮圆心为 $C$，始终紧贴大齿轮内壁匀速滚动；$P$ 为小齿轮边缘上的一点。
已知小齿轮的直径与大齿轮的半径相等（$R = 2r$）。判断：
A. $P$ 的速度方向指向 $O$；        B. $P$ 的加速度方向指向 $C$；
C. $P$ 的周期是 $C$ 的两倍；        D. $PO$ 越小，$P$ 的加速度越大。
核心物理切入点：旋转矢量合成
  • 设 $t=0$ 时，小齿轮圆心在 $(r,0)$，点 $P$ 与内壁接触于 $(2r,0)$。
  • 小齿轮圆心 $C$ 绕 $O$ 以角速度 $\omega$ 公转，转角 $\theta = \omega t$。
  • 关键问题：无滑滚动条件下，小齿轮自转角速度 $\omega_s$ 与公转角速度 $\omega$ 满足什么定量关系？

【例题 1】严格数理推导与选项深度辨析

1. 无滑滚动约束与运动方程推导
在大齿轮外圆弧上纯滚动，弧长相等： $$s = R\theta = 2r\theta = r\phi_{\text{相对}} \implies \phi_{\text{相对}} = 2\theta$$ 内切滚动自转与公转反向，惯性系中绝对自转角 $\theta_s = \theta - 2\theta = -\theta = -\omega t$。复数合成 $P$ 点位置： $$\begin{aligned} z_P(t) &= z_C(t) + z_{CP}(t) = r e^{i\omega t} + r e^{-i\omega t} \\ &= 2r\cos(\omega t) = R\cos(\omega t) \end{aligned}$$ 即 $\vec{r}_P(t) = \big(R\cos(\omega t),\, 0\big)$：$P$ 沿过 $O$ 的固定直径做简谐振动！（图西双圆 / Tusi Couple）
2. 速度、加速度与四选项逐一剖析
由 $x_P = R\cos(\omega t)$ 得 $v_P = -R\omega\sin(\omega t)$，$\vec{a}_P = -\omega^2\vec{r}_P$：
  • A 项：$P$ 沿直径往复直线运动，靠近 $O$ 时指向 $O$，远离 $O$ 时背离 $O$（仅直线恒过 $O$，矢量方向非恒指向 $O$）。
  • B 项（错）：$\vec{a}_P = -\omega^2 \vec{r}_P$，加速度恒指向 $O$，而非 $C$。
  • C 项（错）：$T_P = \frac{2\pi}{\omega} = T_C$，两者周期相等。
  • D 项（错）：$|\vec{a}_P| = \omega^2\cdot PO$，$PO$ 越小加速度越小。

【例题 1 拓展】一般情形 $R \neq 2r$：内摆线（Hypocycloid）

一般半径比 $k = R/r$ 的复数轨道方程
设大圆半径 $R$、小圆半径 $r$（$k = R/r$）。无滑滚动时，小圆绝对自转角 $\theta_s = \theta - \frac{R}{r}\theta = -(k-1)\theta$，故 $P$ 点轨迹为内摆线： $$z_P(\theta) = (R - r)e^{i\theta} + r\,e^{-i(k-1)\theta} \qquad \big(\text{注：}k=2 \text{ 退化为直线简谐振动；一般情形即“两圆本轮”}\big)$$
$R = 3r$（三尖瓣线）
$z_P = r(2e^{i\theta} + e^{-2i\theta})$
$R = 4r$（星形线）
$x^{2/3} + y^{2/3} = R^{2/3}$
$R = 5r$（五尖内摆线）
非整数 $k=p/q$ 呈星形，$k\notin\mathbb{Q}$ 永不闭合

§7-2 简谐振动的叠加：同方向合成与拍现象

1. 同方向、同频率简谐振动合成
设 $x_1 = A_1\cos(\omega t + \varphi_1)$，$x_2 = A_2\cos(\omega t + \varphi_2)$。
用复振幅合成 $\tilde{A} = \tilde{A}_1 + \tilde{A}_2 = A_1 e^{i\varphi_1} + A_2 e^{i\varphi_2}$： $$A = \sqrt{A_1^2 + A_2^2 + 2A_1 A_2\cos(\varphi_2 - \varphi_1)}$$ $$\tan\varphi = \frac{A_1\sin\varphi_1 + A_2\sin\varphi_2}{A_1\cos\varphi_1 + A_2\cos\varphi_2}$$
  • 同相加强：$\Delta\varphi = 2k\pi \implies A = A_1 + A_2$
  • 反相减弱：$\Delta\varphi = (2k+1)\pi \implies A = |A_1 - A_2|$
2. 同方向、相近频率合成：拍现象
设 $A_1 = A_2 = A$，$\omega_1 \approx \omega_2$，利用和差化积： $$\begin{aligned} x &= A\cos\omega_1 t + A\cos\omega_2 t \\ &= \underbrace{\left[2A\cos\!\left(\frac{\omega_1-\omega_2}{2}t\right)\right]}_{\text{缓变振幅（包络）}} \cos\!\left(\frac{\omega_1+\omega_2}{2}t\right) \end{aligned}$$ 振幅绝对值在一个包络周期内出现 2 次极大，故拍频 $\nu_{\text{拍}} = |\nu_1 - \nu_2|$（乐器校音、外差检测基础）。

§7-3 阻尼振动、受迫振动与共振

1. 阻尼振动（线性阻力 $F_r = -\gamma\dot{x}$）
$\ddot{x} + 2\beta\dot{x} + \omega_0^2 x = 0\ (\beta = \frac{\gamma}{2m})$。
欠阻尼（$\beta < \omega_0$）：$x(t) = A_0 e^{-\beta t}\cos(\omega_d t + \varphi_0)$，$\omega_d = \sqrt{\omega_0^2 - \beta^2}$。（临界/过阻尼无往复振荡。）
2. 受迫振动稳态解与振幅共振
受驱动力 $F = F_0\cos\omega t$（$f_0 = F_0/m$）： $$\ddot{x} + 2\beta\dot{x} + \omega_0^2 x = f_0\cos\omega t$$ 复数法求稳态特解 $x = A\cos(\omega t + \varphi)$： $$A(\omega) = \frac{f_0}{\sqrt{(\omega_0^2 - \omega^2)^2 + 4\beta^2\omega^2}}, \quad \tan\varphi = -\frac{2\beta\omega}{\omega_0^2 - \omega^2}$$ 令 $\frac{\mathrm{d}A}{\mathrm{d}\omega}=0$ 得位移共振频率：$\omega_r = \sqrt{\omega_0^2 - 2\beta^2}$。

§7-6 一维波动方程的微元法推导

微元受力与牛顿第二定律
考虑线密度为 $\mu$、张力为 $T$ 的均匀细弦上微元 $[x, x+\mathrm{d}x]$，质量 $\mathrm{d}m = \mu\mathrm{d}x$。
小振幅近似下，倾角 $\theta$ 很小，$\sin\theta \approx \tan\theta = \frac{\partial y}{\partial x}$： $$\begin{aligned} \mathrm{d}F_y &= T\sin\theta(x+\mathrm{d}x) - T\sin\theta(x) \\ &\approx T\!\left(\left.\frac{\partial y}{\partial x}\right|_{x+\mathrm{d}x} - \left.\frac{\partial y}{\partial x}\right|_x\right) = T\frac{\partial^2 y}{\partial x^2}\,\mathrm{d}x \end{aligned}$$ 由 $\mathrm{d}F_y = \mathrm{d}m\,\frac{\partial^2 y}{\partial t^2} = \mu\mathrm{d}x\,\frac{\partial^2 y}{\partial t^2}$，导出一维波动方程： $$\frac{\partial^2 y}{\partial t^2} = u^2 \frac{\partial^2 y}{\partial x^2}, \qquad u = \sqrt{\frac{T}{\mu}}$$
达朗贝尔通解
任何形如 $y = f(x-ut) + g(x+ut)$ 的二阶可微函数均满足一维波动方程。

§7-6 波的能量、能流与能流密度

1. 弹性介质微元的动能与势能
对体积元 $\mathrm{d}V$（密度 $\rho$），简谐波 $y = A\cos(\omega t - kx)$： $$\begin{aligned} \mathrm{d}E_k &= \frac{1}{2}\rho\mathrm{d}V\!\left(\frac{\partial y}{\partial t}\right)^2 = \frac{1}{2}\rho\mathrm{d}V\,\omega^2 A^2\sin^2(\omega t - kx) \\ \mathrm{d}E_p &= \frac{1}{2}\rho u^2\mathrm{d}V\!\left(\frac{\partial y}{\partial x}\right)^2 = \frac{1}{2}\rho\mathrm{d}V\,\omega^2 A^2\sin^2(\omega t - kx) \end{aligned}$$ 重要结论：行波中微元的 $\mathrm{d}E_k = \mathrm{d}E_p$（同相变化），微元能量不守恒，而是不断向下游传递！
2. 能量密度与能流密度（波强）
  • 瞬时能量密度： $$w = \frac{\mathrm{d}E_k+\mathrm{d}E_p}{\mathrm{d}V} = \rho\omega^2 A^2\sin^2(\omega t - kx)$$
  • 平均能量密度： $$\bar{w} = \frac{1}{2}\rho\omega^2 A^2$$
  • 平均能流密度（波强）： $$I = \bar{w}\,u = \frac{1}{2}\rho u\omega^2 A^2$$ 其中 $Z = \rho u$ 称为介质的特性声阻抗。

§7-7 波的干涉与驻波

1. 波的干涉（相干叠加）
相干条件：频率相同、振动方向相同、相位差恒定。
两波源到点 $P$ 的相位差： $$\Delta\varphi = (\varphi_2 - \varphi_1) - \frac{2\pi}{\lambda}(r_2 - r_1)$$
  • 干涉加强：$\Delta\varphi = \pm 2k\pi$（同相源时 $\Delta r = k\lambda$）
  • 干涉减弱：$\Delta\varphi = \pm(2k+1)\pi$（同相源时 $\Delta r = (k+\frac{1}{2})\lambda$）
2. 驻波方程与半波损失
两列等幅反向简谐波叠加： $$y = A\cos(\omega t - kx) + A\cos(\omega t + kx) = \underbrace{\big[2A\cos(kx)\big]}_{\text{空间振幅分布}} \cos(\omega t)$$
  • 波腹：$|kx| = n\pi \implies x = n\frac{\lambda}{2}$；波节：$x = \big(n+\frac{1}{2}\big)\frac{\lambda}{2}$
  • 半波损失：波由波疏介质垂直入射波密介质反射时，反射波相位突变 $\pi$（等效波程差 $\lambda/2$）。

【例题 2】两端固定弦线的驻波与本征频率

题目
一根长为 $L = 0.60\text{ m}$、线密度为 $\mu = 2.0\times 10^{-3}\text{ kg/m}$ 的琴弦两端固定，承受张力 $T = 72\text{ N}$。
(1) 推导弦上能形成的驻波波长 $\lambda_n$ 与本征频率 $f_n$；    (2) 若弦上观察到 $4$ 个波节（含两端），求此时振动频率与波速。
数理推导与解答
  1. 边界条件与波长量子化：两端固定必为波节，相邻波节间距 $\frac{\lambda}{2}$，故弦长为半波长的整数倍： $L = n\cdot\frac{\lambda_n}{2} \implies \lambda_n = \frac{2L}{n}\ (n = 1, 2, 3, \dots)$。
  2. 波速与本征频率：横波波速 $u = \sqrt{\frac{T}{\mu}} = \sqrt{\frac{72}{2.0\times 10^{-3}}} \approx 189.7\text{ m/s}$，本征频率： $$f_n = \frac{u}{\lambda_n} = \frac{n}{2L}\sqrt{\frac{T}{\mu}} = n f_1 \qquad (\text{基频 } f_1 \approx 158.1\text{ Hz})$$
  3. $4$ 个波节情形：含两端共 $4$ 个波节，弦被分为 $n = 4 - 1 = 3$ 段半波（第 3 谐波），故： $f_3 = 3 f_1 = \frac{3\times 189.7}{2\times 0.60} \approx \mathbf{474.3\text{ Hz}}$。

§7-8 多普勒效应的理论推导

1. 相对运动下的波长与频率变换
设介质静止，波速为 $u$，波源固有频率为 $f$：
  • 波源以 $v_S$ 运动：在一个周期 $T=1/f$ 内，波前前进 $uT$，波源移动 $v_S T$，有效波长被压缩（靠近）或拉伸（远离）： $$\lambda' = \frac{u \mp v_S}{f}$$
  • 观察者以 $v_O$ 运动：波前相对观察者的速度变为 $u \pm v_O$，单位时间接收到的完整波数即观测频率： $$f' = \frac{u \pm v_O}{\lambda'} = \frac{u \pm v_O}{u \mp v_S}\, f$$
2. 符号判定法则与声波分类（§7-9）
  • 符号法则：
    • 观察者向波源运动：分子取 $+$；
    • 波源向观察者运动：分母取 $-$；
    • 简记：“靠近使 $f'$ 变大，远离使 $f'$ 变小”。
  • 声波频段（§7-9）：
    • 次声波：$< 20\text{ Hz}$（地震/海啸监测）
    • 可听声：$20\text{ Hz} \sim 20\text{ kHz}$
    • 超声波：$> 20\text{ kHz}$（医学成像/测速）

【例题 3】多普勒效应在超声测速中的综合应用

题目
路旁一静止的超声波测速仪发射频率为 $f_0 = 40.0\text{ kHz}$ 的超声波，一辆汽车以速度 $v = 20\text{ m/s}$ 沿直线迎面驶向测速仪（空气声速 $u = 340\text{ m/s}$）。
求：(1) 测速仪接收到经汽车反射回来的超声波频率 $f''$；    (2) 反射波与发射波叠加产生的拍频 $\Delta f$。
两步法严谨推导
  1. 第一步（发射器 $\to$ 汽车）：发射器静止（$v_S=0$），汽车为迎面观察者（$v_O = v$）：$f' = \frac{u + v}{u}\,f_0$。
  2. 第二步（汽车反射 $\to$ 发射器）：汽车作为迎面二次波源（$v_S = v$，频率 $f'$），测速仪静止： $$f'' = \frac{u}{u - v}\,f' = \frac{u + v}{u - v}\,f_0 = \frac{340 + 20}{340 - 20} \times 40.0\text{ kHz} = \mathbf{45.0\text{ kHz}}$$
  3. 拍频计算：反射波与原发射波混频，测得拍频即可直接反演车速： $$\Delta f = f'' - f_0 = \frac{2v}{u - v}\,f_0 = \mathbf{5.0\text{ kHz}} \qquad \left(v \ll u \text{ 时近似 } \Delta f \approx \frac{2v}{u}f_0\right)$$

2. 人形机器人关节抑振与阻抗控制
  • 谐波减速器与柔性关节：电机-减速器-连杆可建模为阻尼受迫振子 $\ddot{\theta} + 2\zeta\omega_n\dot{\theta} + \omega_n^2\theta = \tau/I$。
  • 阻抗控制（Impedance Control）：软件实时调节等效刚度 $k$ 与阻尼 $\gamma$，使阻尼比 $\zeta \approx 0.707$（最佳阻尼），既快速响应又避免落地冲击引发剧烈振荡。
  • 规避结构共振：步态规划避开机械臂/腿部固有频率 $\omega_n$。

现实应用（二）：建筑抗振、声学降噪与医疗传感

建筑与桥梁抗振（§7-3）
  • 台北 101 调谐质量阻尼器（TMD）：660 吨钢球作为次级振子，固有频率与大楼匹配，通过反相受迫振动耗散风致能量。
  • 塔科马海峡大桥（1940）：卡门涡街脱落频率与桥体扭转固有频率耦合导致剧烈自激共振坍塌。
主动降噪耳机 ANC（§7-7）
  • 相消干涉原理：外部麦克风采集低频噪声 $y_1 = A\cos(\omega t + \varphi)$。
  • DSP 芯片实时生成等幅反相声波 $y_2 = A\cos(\omega t + \varphi + \pi)$。
  • 耳道内叠加 $y_1 + y_2 = 0$，实现低频环境噪声精准抵消。
医学多普勒超声（§7-8~7-9）
  • 探头发射 $2\sim 10\text{ MHz}$ 超声波，经流动红细胞散射产生多普勒频移： $$\Delta f = \frac{2v\cos\theta}{u}\,f_0$$
  • 实时无创测量血流速度与方向（红迎蓝离），用于心脏瓣膜与血管狭窄诊断。

跨学科专题（一）：从旋转矢量到“多圆画任意曲线”

1. 思想跃迁：从例题 p3 到傅里叶本轮（Epicycles）
  • 1 个圆：$z(t) = c_1 e^{i\omega_0 t}$ $\longrightarrow$ 匀速圆周运动；
  • 2 个圆（例题 p3 图西双圆）：$z(t) = r e^{i\omega_0 t} + r e^{-i\omega_0 t}$ $\longrightarrow$ 直线简谐振动；
  • $2N+1$ 个圆首尾相连：将复平面上任意周期封闭曲线 $z(t) = x(t) + i y(t)$ 展开为复数傅里叶级数： $$z(t) = \sum_{n=-N}^{N} c_n\, e^{i n \omega_0 t}, \qquad \omega_0 = \frac{2\pi}{T}$$
2. 系数 $c_n$ 的正交性推导与几何意义
利用复指数基函数的正交性： $$\frac{1}{T}\int_0^T e^{i(m-n)\omega_0 t}\,\mathrm{d}t = \delta_{mn} = \begin{cases} 1, & m=n \\ 0, & m\neq n \end{cases}$$ 两边同乘 $e^{-i k \omega_0 t}$ 并在 $[0,T]$ 积分，导出： $$c_k = \frac{1}{T}\int_0^T z(t)\,e^{-i k \omega_0 t}\,\mathrm{d}t = |c_k|\,e^{i\varphi_k}$$ 每个 $c_k e^{ik\omega_0 t}$ 都是一个旋转圆：
  • 半径 $R_k = |c_k|$，初始相位 $\varphi_k = \arg(c_k)$；
  • 转速 $k\omega_0$（$k>0$ 逆时针，$k<0$ 顺时针）。

跨学科专题（二）：多圆逐阶逼近封闭正方形

正方形的复数傅里叶展开式
对顶点在 $(\pm 1, \pm 1)$ 的正方形沿周长匀速参数化，由对称性仅保留 $n \equiv 1 \pmod 4$ 的谐波分量： $$z(t) = c_1\!\left(e^{it} - \frac{1}{9}e^{-3it} - \frac{1}{25}e^{5it} + \frac{1}{49}e^{-7it} + \cdots\right)$$ 其中主圆半径 $c_1 = \frac{8\sqrt{2}}{\pi^2} \approx 1.146$，高阶圆半径按 $\mathbf{1/n^2}$ 快速衰减。
直观规律
  • 低频大圆决定图形的整体轮廓；
  • 高频小圆负责雕琢尖角与细节（如直角拐点）；
  • 只要圆的数量足够多，任何封闭曲线（汉字、人像轮廓等）都能被精准合成！

跨学科专题（三）：旋转本轮动态绘迹与 FFT 算法

计算机如何自动算出所有“圆”？—— FFT
曲线采样为 $N$ 个离散复数点 $z[0],\dots,z[N-1]$，由离散傅里叶变换（DFT）求各圆参数： $$c_k = \frac{1}{N}\sum_{n=0}^{N-1} z[n]\,e^{-i\frac{2\pi}{N}kn}$$ 借助快速傅里叶变换（FFT），复杂度由 $O(N^2)$ 降至 $O(N\log N)$，毫秒级即可分解出成千上万个旋转圆。
核心工程与 CS 应用
  • 信号与音频压缩：MP3 / AAC / JPEG 仅保留幅值最大的少量“主圆”即可高保真还原。
  • 现代通信与语音：5G OFDM 正交多载波调制、语音识别语谱图（STFT）分析。
